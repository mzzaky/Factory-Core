====================================
FactoryCore Update Log - v1.2.7
====================================

[Bug Fixes]
- Fixed an issue where the "Factories Owned" counter in MyFactoriesGUI did not count player-created factories.
- Fixed an issue in MyFactoriesGUI where it read the wrong config key for factory limit (`factory.max-ownership` instead of `factory.max-factories-per-player`).
- Fixed an issue where the `/fc sell <factory_id>` command failed to work for player-created factories, as it only checked the admin FactoryManager.
- Fixed tab-complete for `/fc sell`, `/fc tp`, and `/fc gui` to correctly include player-created factory IDs.
- Fixed FactoryCore PlaceholderAPI placeholders (`%factorycore_factories_owned%`, `%factorycore_factories_running%`, `%factorycore_total_value%`, `%factorycore_highest_level%`) not including statistics from player-created factories.
- Fixed an issue where player-created factories did not appear in the Employee Shop and Employees Center GUIs, preventing players from assigning employees to them.
- Fixed an issue in MarketplaceGUI where clicking items in the player's inventory to register them for sale did not work due to hub GUI click prevention logic.
- Fixed a critical core bug where production cycles and upgrade timers for player-created factories never progressed because their manager wasn't hooked into the central server scheduler.
- Fixed a massive synchronization issue where multiple actions inside the Factory Menu (Start Production, Access Recipes, Upgrade, Manage Storage) refused to work or threw errors for player-created factories due to only checking the admin Factory manager.
- Fixed an issue where the sell confirmation prompt in My Factories menu would fail to open/process for player-created factories.
- Added full support for vanilla input materials to deposit and withdraw correctly from player-created factories, mirroring the behavior of admin factories.
- Fixed an issue where internal Hub GUI placeholders (like `{factory_owned_count}`, `{factory_running_count}`, `{factory_total_value}`) and the "Assigned Employees" counter ignored player-created factories.
- Fixed the Quick Stats breakdown menu in the Hub GUI to correctly include and display a player's admin factories and player-created factories together.
- Fixed an issue where player-created factories were not assessed for taxes — TaxManager now calculates and tracks tax records for both admin and player-created factories.
- Fixed an issue where player-created factories were not included when paying taxes individually, paying all taxes at once, or retrieving tax totals/records.
- Fixed an issue where late fee notifications for overdue taxes only notified admins, not player-factory owners.
- Fixed an issue where employee salary invoices were only generated for admin-created factories. PlayerFactory employees now also generate salary invoices on the same cycle, applying research salary reductions as expected.
- Fixed an issue in InvoiceCenterGUI where invoice items from player-created factories always displayed "Unknown" as the factory name, as it only looked up the factory ID from the admin FactoryManager. Factory type (Admin/Player) is now also shown on each invoice item.
- Fixed an issue in TaxCenterGUI where player-created factories were not listed in the Tax Center menu, not counted in the "Factories Taxed" header stat, and excluded from the Tax Calculator preview. The Tax Center now shows both admin and player factories side-by-side, with their type clearly labeled.
- Fixed a critical issue in NPCManager where employees assigned to player-created factories caused a continuous "Respawning missing NPC" loop in the console. The root causes were: (1) spawnNPCWithTemplate() only validated factory IDs against the admin FactoryManager, causing NPC spawns for player factories to silently fail; (2) the respawn scheduler had no guard for orphaned NPC records whose factory no longer exists, causing it to retry respawning indefinitely. Additionally, a hotfix was implemented to automatically "unassign" any orphaned NPCs (returning them to the player's employee pool) if they are detected in a deleted/sold player factory. Player factories now also properly unassign NPCs immediately when the factory is sold.
- Fixed OutputStorageGUI so it can now be opened correctly by player-created factories. Previously, the GUI lookup strictly checked the admin FactoryManager, causing it to fail silently when a player factory's NPC was left-clicked. Items can now be safely withdrawn (including vanilla items).
- Fully synchronized the crafting/production completion mechanism for player-created factories in PlayerFactoryManager. Completing production in a player factory now correctly awards the "early_prototype" and "mass_producer" achievements, adds progress to the "Industrial Hustle" daily quest, and triggers the configured completion sound and title notifications, exactly mirroring admin factories.
- Improved MyFactoriesGUI item names and lore for better readability. Huge raw UUID values have been reformatted to display only the first 8 characters and are enclosed cleanly in parentheses (e.g. `Iron Smeltery (#a1b2c3d4)` instead of massive raw strings). The full ID remains functional for background event clicks.
