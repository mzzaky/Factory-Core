Overview

FactoryCore API memungkinkan developer lain untuk berinteraksi dengan sistem FactoryCore secara langsung melalui kode. Dengan API ini, Anda dapat menghubungkan plugin buatan Anda untuk mendapatkan data pabrik, memodifikasi penyimpanan, mengecek status produksi, hingga memberikan limit custom kepada player tertentu.

💡 Kenapa Menggunakan API?
API disediakan secara terstruktur dalam kelas FactoryCoreAPI. Semua interaksi yang melibatkan data pabrik, resource, dan NPC sebaiknya dilakukan melalui API ini untuk menghindari kerusakan data (data corruption).

Setup & Instalasi

Langkah pertama sebelum Anda menggunakan API dari FactoryCore adalah memastikan plugin Anda mengenali FactoryCore sebagai dependensi.

1. Tambahkan ke plugin.yml

Pastikan Anda menambahkan FactoryCore ke dalam depend atau softdepend di file plugin.yml Anda agar plugin Anda dimuat setelah FactoryCore siap.

YAML 
name: PluginKerenSaya
version: 1.0
main: com.plugin.keren.MainClass
depend: [FactoryCore]

2. Tambahkan Library (Jika menggunakan Maven/Gradle)

Saat ini Anda dapat menambahkan jar FactoryCore secara lokal ke project Anda untuk mengakses kelas dan fungsinya ketika proses kompilasi.

Mengambil API Instance

Cara paling mudah untuk menggunakan semua manager dan fungsi adalah melalui kelas FactoryCoreAPI.

JAVA 
import com.aithor.factorycore.api.FactoryCoreAPI;

// Inisialisasi API
FactoryCoreAPI api = new FactoryCoreAPI();

Fitur Utama API

API dikelompokkan menjadi beberapa kategori fungsi utama yang dapat Anda panggil.

Kategori Contoh Method Deskripsi
Factory Data api.getFactory(String factoryId)
api.getFactoriesByOwner(UUID owner) 		Mengambil objek Factory, daftar pabrik, dan status kepemilikan pabrik seorang player.
Storage & Resource api.addToStorage(id, res, amt)
api.giveResource(player, res, amt) 		Menambahkan / mengurangi item dari sistem penyimpanan (input/output storage) atau ID resource.
Production api.isProducing(factoryId)
api.getProductionProgress(String) 		Mengecek apakah pabrik sedang berjalan dan mengetahui persentase progres produksinya (0.0 ke 1.0).
Economy & Tax api.getPlayerInvoices(UUID)
api.payInvoice(Player, ID) 		Berinteraksi dengan sistem Invoice & Pajak, memberikan tagihan atau membayarnya via kode.
Employee (NPC) api.spawnNPCWithTemplate(...)
api.isFactoryNPC(UUID) 		Memunculkan NPC secara dinamis atau mengecek apakah suatu Entity merupakan karyawan pabrik.

Contoh Penggunaan

Berikut adalah contoh implementasi penuh bagaimana Anda dapat menggunakan FactoryCoreAPI untuk mengecek statistik pabrik milik player yang login dan menambahkan item ke penyimpanannya.

JAVA 
package com.yourplugin.test;

import com.aithor.factorycore.api.FactoryCoreAPI;
import com.aithor.factorycore.models.Factory;
import org.bukkit.entity.Player;
import org.bukkit.event.EventHandler;
import org.bukkit.event.Listener;
import org.bukkit.event.player.PlayerJoinEvent;
import org.bukkit.plugin.java.JavaPlugin;

import java.util.List;

public class YourPlugin extends JavaPlugin implements Listener {

    private FactoryCoreAPI api;

    @Override
    public void onEnable() {
        // Inisialisasi API saat plugin dihidupkan
        api = new FactoryCoreAPI();
        getServer().getPluginManager().registerEvents(this, this);
    }

    @EventHandler
    public void onPlayerJoin(PlayerJoinEvent event) {
        Player player = event.getPlayer();
        
        // Mendapatkan daftar pabrik milik player
        List<Factory> factories = api.getFactoriesByOwner(player.getUniqueId());
        
        if (!factories.isEmpty()) {
            player.sendMessage("Selamat datang kembali Bos! Anda memiliki " + factories.size() + " pabrik.");
            
            for (Factory factory : factories) {
                // Mengecek apakah pabrik sedang produksi
                if (api.isProducing(factory.getId())) {
                    double progress = api.getProductionProgress(factory.getId());
                    int percent = (int)(progress * 100);
                    player.sendMessage("Pabrik " + factory.getId() + " sedang memproduksi dengan progress: " + percent + "%");
                }
            }
        } else {
            // Contoh menggunakan API untuk memberikan item modal
            api.giveResource(player, "iron_ingot", 10);
            player.sendMessage("Ini 10 Besi sebagai modal mendirikan pabrik!");
        }
    }
}
